About the Project

Know Your Resume. Know Your Next Move.

Resume Analyzer is a web-based application designed to help job seekers understand how well their resume matches a specific job role. Instead of manually comparing a resume with job requirements, the system automatically analyzes the uploaded resume and provides meaningful insights about the candidate's skills, education, experience, and overall profile.

The application allows users to upload their resume in PDF or DOCX format and select a target job role. The system extracts relevant information from the resume, identifies the candidate's skills, and compares them with the skills required for the selected role.

What the system provides

  • Resume Analysis – Extracts important information such as skills, education, and experience.
  • Skill Matching – Compares the candidate's skills with the required skills for the selected job role.
  • Matched Skills – Shows the skills already present in the resume
  • Missing Skills – Identifies important skills that may need to be developed.
  • Resume Score – Provides an overall score based on the resume's relevance to the selected role.
  • Recommendations – Gives actionable suggestions to improve the resume and prepare for the target role.
  • LinkedIn Detection – Checks whether LinkedIn information is included in the resume.
  • Interactive Dashboard – Presents the analysis in an easy-to-understand format.

How It Works

Upload Resume → Extract Resume Data → Analyze Skills → Select Target Role → Compare Required Skills → Generate Score → Provide Recommendations

The project focuses on making resume analysis simple, transparent, and useful for career preparation. Rather than only giving a score, it helps users understand why their resume received that score and what they can improve.

Technology

The project is developed using Python and Flask, with dedicated modules for resume parsing, resume analysis, job-role requirements, and skill matching. PDF and DOCX resumes are processed to extract relevant information, which is then used to generate the final analysis.
